Who Am I?

I go by Leo Mercer. I build things that run on Linux, customize the graphical environments I spend most of my day in, and write about the process when it's interesting enough.

This site is both a portfolio and a public notebook — documenting every desktop rice, every technical experiment, every time I spent six hours making a terminal prompt look better because that's what matters to me.

Philosophy

Desktop ricing isn't vanity. It's the practice of owning your computing environment at the pixel level. Every color choice, every spacing decision, every custom script is a statement about how you want to interact with your machine.

I believe in minimal external dependencies — no frameworks, no CDNs, no analytics trackers on my site. The tools I use should be transparent, local-first, and under my control. This blog reflects that: pure HTML/CSS/JS, built locally, deployed to GitHub Pages.

Why This Blog?

I've spent months ricing a Pop!_OS desktop with Catppuccin Mauve colors, Polybar, Conky, and patched GNOME Shell CSS. I want to document the process — the failures, the breakthroughs, the config files that finally worked. This blog is the archive.

It's also meant to be useful to others: if you're trying to figure out how to patch Catppuccin shell CSS for a translucent panel, or configure btop with custom themes, or get Polybar running on X11 — the answers are here.
